# บัญชีบ้านเรา

เว็บต้นแบบบันทึกรายรับรายจ่ายและแจ้งเตือนเมื่อใช้ถึง 80% ของงบหรือเกินงบ

## ข้อมูลและความเป็นส่วนตัว

- เว็บนี้เป็นแบบไม่ซิงข้อมูล แต่ละคนที่เปิดเว็บจะมีข้อมูลของตัวเองในเบราว์เซอร์และอุปกรณ์นั้น
- รายการและงบประมาณเก็บด้วย `localStorage` ในเบราว์เซอร์ ไม่ได้ส่งไปฐานข้อมูลกลาง
- การล้างข้อมูลเว็บไซต์หรือเปลี่ยนเบราว์เซอร์/อุปกรณ์อาจทำให้ข้อมูลเดิมไม่ปรากฏ
- ปุ่มเข้าสู่ระบบเป็นเพียงตัวอย่างหน้าจอ ยังไม่มีระบบบัญชีผู้ใช้จริง

## เผยแพร่ด้วย GitHub Pages

1. สร้าง GitHub repository ใหม่ และอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปไว้ที่ root ของ repository
2. ตั้งค่า repository ให้ใช้ GitHub Actions สำหรับ Pages หาก GitHub แสดงหน้าตั้งค่า Pages ให้เลือก **GitHub Actions** เป็น Build and deployment source
3. รอ workflow ชื่อ **Publish static budget app** ทำงานสำเร็จ แล้วเปิด URL ที่ GitHub Pages แสดงในแท็บ Actions หรือ Settings → Pages

ทุกคนที่มี URL จะเปิดเว็บได้ แต่ข้อมูลของแต่ละคนจะแยกเก็บในเบราว์เซอร์ของตัวเอง
